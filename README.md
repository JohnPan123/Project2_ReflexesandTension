# Project2_ReflexesandTension

 ~Controls~
 - Use the WASD keys for movement.
 - Use the Mouse to control your camera.
 - Use the Right Mouse Button to boost.

 ~How To Play~
 - When you spawn in, the turrets that surround you will start firing  
    bullets at you; if enough bullets hit you, you lose.
 - If you survive long enough, you win!
 - Power Up: The bar on top of your player is your boost bar. It 
   glows when you can boost.
